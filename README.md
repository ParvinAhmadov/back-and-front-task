🚀 Full-Stack User Management Task
Bu layihə müasir veb texnologiyalarından istifadə edərək hazırlanmış, həm backend, həm də frontend hissələrini özündə birləşdirən kompleks bir tapşırıqdır. Layihənin əsas məqsədi effektiv məlumat idarəetməsi və istifadəçi interfeysinin inteqrasiyasını təmin etməkdir.

🛠 Texnoloji Stack
Frontend
React.js & TypeScript: Güclü tip təhlükəsizliyi və komponent əsaslı arxitektura.

Tailwind CSS: Modern və pixel-perfect UI dizaynı.

Axios: API sorğularının idarə edilməsi.

React Router: Səhifələrarası sürətli keçid və naviqasiya.

Backend
Node.js & Express.js: Sürətli və genişləndirilə bilən server tərəfi.

REST API: Standartlara uyğun backend arxitekturası.

Middleware Integration: Təhlükəsizlik və məlumat emalı üçün xüsusi funksiyalar.

✨ Əsas Özəlliklər
CRUD Operations: İstifadəçilərin (və ya tapşırıqların) yaradılması, oxunması, yenilənməsi və silinməsi.

Full Integration: Frontend və Backend arasında tam sinxronizasiya.

Responsive Design: Həm desktop, həm də mobil cihazlar üçün optimallaşdırılmış interfeys.

Clean Code: SOLID prinsiplərinə uyğun, oxunaqlı və təkrar istifadə edilə bilən kod strukturu.

⚙️ Quraşdırılma və İşə Salma
Layihəni lokal mühitdə işə salmaq üçün aşağıdakı addımları izləyin:

1. Repozitoriyanı klonlayın
Bash
git clone https://github.com/ParvinAhmadov/back-and-front-task.git
cd back-and-front-task
2. Backend-i işə salın
Bash
cd backend
npm install
npm start
3. Frontend-i işə salın
Bash
cd frontend
npm install
npm start
